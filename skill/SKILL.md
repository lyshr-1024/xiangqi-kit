# 象棋（Xiangqi）

## 铁律

**棋盘状态只存在于引擎里，不存在于你的记忆里。** LLM 靠文字记棋盘，
二三十步后必然记错子的位置、走出不合法的棋。因此：

- 任何走子、判断"这步能不能走"、报告局面，都必须调用 CLI，以其输出为准。
- 绝不在脑内推演"现在马应该在哪"——用 `show`。
- 绝不自己判断走法是否合法——`move` 会校验，非法会报错并 exit 1。
- 用户报的着法解析失败时，跑 `legal` 找相近的合法写法，向用户确认。

## CLI

入口是本目录的 `./xq`（零依赖，系统 python3 即可）。棋局存在
`~/.xiangqi/games/<name>.json`，跨会话自动续棋。

| 命令 | 作用 |
|---|---|
| `xq new [--fen FEN] [--force]` | 开新棋局（默认标准开局） |
| `xq show` | 显示棋盘与轮走方/将军/终局状态 |
| `xq move <记谱>` | 走一步，如 `xq move 炮二平五` |
| `xq ai` | 让 AI 走一步 |
| `xq undo` | 悔一步棋 |
| `xq legal` | 列出当前所有合法着法 |
| `xq fen` | 输出当前局面 FEN |
| `xq history` | 显示完整棋谱 |

所有命令支持 `-n <名字>` 管理多盘棋（默认 `default`）。

## 记谱速查

- 红方用汉字数字（炮二平五），黑方用阿拉伯数字（马8进7）；解析时两者混用也能识别。
- 路数从各自右手数起；车炮兵帅进退记步数，马象士进退记到达路数。
- 同线双子用前/后：前车进三、后炮平5。

## 典型流程

**用户想下棋**：`xq new`（已有棋局则先问是续棋还是重开），把 `show` 的
棋盘原样贴给用户（放代码块里），约定用户执红或黑。

**用户报一步**：`xq move <着法>` → 成功后把新棋盘贴给用户；轮到 AI 就
`xq ai`，并把 AI 的着法与棋盘一并报告。

**复盘**：`xq history` 看棋谱，`xq undo` 回退，配合 `show` 逐步讲解。

**输出里出现「棋局结束」**：向用户宣布结果（将死/困毙/三次重复判和），
不要再试图走子。
